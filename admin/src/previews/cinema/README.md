# 光影的旅程：Three.js 正式场景与独立预览

在 `admin` 目录执行 `npm run dev -- --host 127.0.0.1 --port 5173`，打开：

http://127.0.0.1:5173/cinema-preview.html

32 秒时间线：胶卷放映机（0s）、黑白电影（5s）、彩色电影（9s）、CRT（13s）、LCD（19s）、手机/笔记本/平板（24s）。支持播放/暂停、重播、章节跳转、进度拖动和全屏。空格播放/暂停，左右方向键逐秒查看；输入控件保留原生键盘行为。

- `../../setup/cinematic/models.ts`：程序化三维模型、动态山水屏幕着色器、金属与木纹材质。
- `../../setup/cinematic/scene.ts`：Three.js 场景、镜头、光照、时间线和资源释放；控制器提供 `play/pause/seek/dispose`。
- `preview.ts`、`style.css`：独立预览界面，不依赖 setup API。
- 系统开启减少动态效果时，默认不自动播放，采用静止章节画面；后台标签页暂停渲染和计时。

已接入 `SetupCinematicIntro`：32 秒自然结束后进入安装向导，跳过立即继续，WebGL 失败显示静态标识后继续。减少动态效果时只显示最终静止构图 1.5 秒。正式组件采用中英文字幕，不包含预览控制条。此预览与正式组件共用模型、场景和时间线，HTML 仍仅由开发服务器提供，不进入生产构建。
